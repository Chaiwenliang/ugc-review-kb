# 05 · 业界参考与学习路线

> 目标：把前面四章连成一张完整的"认知地图"，对照业界实际做法，并给出一个可落地的系统性学习路径，方便你真正把知识沉淀下来、迁移到自己的业务。

## 一、业界实际是怎么做的（参考与对照）

各大 UGC 平台的审核虽然各有差异，但骨架高度相似，可以对照前四章看看业界怎么落地：

### 抖音 / 快手（短视频）
- 抽帧 + 音频转写 + 多模态模型组合判图/判视频。
- 全量机器初审 + 高命中/低置信进人工，人工审核台 + 兜底抽检。
- 用户分层（创作者等级 / 信用分）联动处置，违规计次累积处罚。

### B 站（中长视频 + 弹幕 + 评论）
- 弹幕评论的高频文本走轻量规则+模型快速过滤。
- 视频走抽帧 + 语音转写，涉政/版权类有专项。
- 社区氛围（打击引战、人身攻击）也纳入机器审核。

### 微博 / 社区类（文本为主）
- 关键词库 + 语义模型组合，涉政/涉黄/广告/辱骂分类。
- 举报 + 用户信用分联动，灰/黑用户加严。
- 抽审 + 申诉平反机制控制误伤。

**共通的骨架（也是前面四章的浓缩）**：
1. 机器全量初筛，命中即判，带置信度。
2. 人工兜底 + 抽检 + 反馈闭环。
3. 策略灰度 + 版本管理 + 可回滚。
4. 用户分层 × 策略联动的二维处置。
5. 指标驱动，周期复盘，持续调优。

> 注意：具体阈值、词表、模型各家是商业机密，公开资料不会给全。所以更值得学的是**这套框架和方法论**，而不是某个具体数字。

## 二、核心概念术语表（快速查）

| 术语 | 含义 |
| --- | --- |
| **机器审核 / 初审** | 用算法/模型自动对内容做分类与处置判断 |
| **人工兜底 / 人审** | 机器拿不准或高危内容，交给人工判断 |
| **策略** | 可配置的判定逻辑：条件→判定→动作（见 02） |
| **用户分层** | 按信用/风险把用户分成白/灰/黑等层级（见 03） |
| **召回率 (Recall)** | 违规内容被抓到的比例；越高漏判越少 |
| **准确率 (Precision)** | 被判违规里真违规的比例；越高误判越少 |
| **误判 (FP)** | 正常内容被误判为违规 |
| **漏判 (FN)** | 违规内容被漏放为正常 |
| **灰度 / 影子模式** | 小流量试跑，不真实处置或只对部分流量处置 |
| **置信度** | 模型对判断的把握程度，驱动进不进人工 |
| **命中策略栈** | 一条内容命中的所有策略的痕迹，供复盘 |
| **反馈闭环** | 人审结论回流给模型/策略，持续调优 |
| **多模态** | 文本/图像/视频/音频多种模态联合判断 |

## 三、系统性学习路线（从零到能搭）

如果你想把这套体系真正学透、能落地，按这个顺序走：

### 阶段 0：建立链路全局观（≈ 先读本仓库 01 章）
- 先弄懂"一条内容从进来到处置"全流程长什么样，别陷进单点。
- 目标：能画出完整链路图。

### 阶段 1：搞懂机器审核怎么"判"（策略 + 规则）
- 学：关键词库、正则、规则引擎、黑白名单。
- 动手：用规则写一个能判"手机号/身份证/广告词"的简单过滤器。
- 目标：理解"命中即判"的规则层。

### 阶段 2：搞懂模型怎么"判"（分类模型）
- 学：文本分类、图像分类、多模态的基础概念（不必会训，先会用）。
- 动手：调用现成 API / 开源模型，给一段文本/一张图打"涉黄/涉政/正常"标签，看置信度。
- 目标：理解"模型输出概率 + 置信度"。

### 阶段 3：搞懂人工怎么"兜底"（人工 + 闭环）
- 学：抽检、人工审核台、反馈闭环、人审真值回流。
- 动手：设计一个"机器判 + 低置信送人审 + 人审结果回流"的最小流程。
- 目标：理解反馈闭环是系统变准的关键。

### 阶段 4：搞懂策略怎么"管理"（灰度 + 版本）
- 学：策略版本、灰度上线、影子模式、回滚。
- 动手：给一条策略加"版本 + 灰度比例"，实现"先试跑再放量"。
- 目标：理解策略是可配置、可灰度、可回滚的工程能力。

### 阶段 5：搞懂用户怎么"分层"（分层 × 策略）
- 学：用户信用分、白/灰/黑分层、分层 × 策略联动。
- 动手：给用户算一个简单信用分，映射到层级，让"同内容不同人不同处置"。
- 目标：理解二维判定（内容 × 用户）。

### 阶段 6：搞懂怎么"复盘"（指标驱动）
- 学：漏判率/误判率/召回/准确、兜底抽样、申诉。
- 动手：定义一套核心指标，做一次"周复盘"，找到一处可调优的点并改掉。
- 目标：理解指标 → 调优 → 复盘 → 再调优的循环。

## 四、怎么把这个仓库沉淀成你自己的能力

这个知识库的价值不在于背下来，而在于**迁移**。建议：
1. **对照自己的业务**：把它当成检查清单，逐条问"我的链路有没有这层、有没有留痕、能不能灰度、有没有复盘"。
2. **补上自己的实践**：把你踩过的坑、你的策略模板、你的分层规则补进对应章节，变成你自己的知识库。
3. **保持迭代**：审核是持续对抗黑产的攻防战，这个知识库也应该持续更新，而不是一次写完。

## 五、一个推荐的落地起点（从最小可运行开始）

别一上来就追求大而全。建议从**最小闭环**起步：
1. 文本内容 + 规则引擎（关键词/正则）→ 先跑起来，能判明确违规。
2. 加一个用户层（白/黑名单）→ 让同内容不同人不同处置。
3. 加一个抽审兜底 → 低置信/高风险送人工，人审结果回流。
4. 加一套指标 → 看漏判/误判率，开始周复盘。

**这一个最小闭环就涵盖了链路、策略、分层、复盘四大能力**。跑通之后，再逐步加模型、加多模态、加灰度。

## 六、一句话总结整套体系

> **机器全量初筛、人工兜底闭环；策略可灰度可回滚、分层与策略联动；用指标驱动、周期复盘、持续进化。**

这就是一套"UGC 内容审核链路 + 策略 + 用户分层 + 复盘"的完整体系，也是本知识库想沉淀给核心内容。
