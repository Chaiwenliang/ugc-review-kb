# UGC 内容审核链路知识库

> 一套系统化的 UGC（图文 / 文本 / 评论 / 短视频）机器审核链路设计与学习沉淀。
> 从核心概念、全流程链路，到策略体系、用户分层管理、指标复盘，再到业界参考与学习路线。

本仓库是一份**偏学习与沉淀**的知识库：重点是把「机器审核 + 策略管理 + 用户分层」这套完整体系结构化地讲清楚，形成可复用的框架，方便复盘、培训和迁移到自己的业务。

---

## 一、这套知识库解决什么问题

UGC 平台在放量增长的同时，必然面临三类问题：

| 问题 | 表现 | 后果 |
| --- | --- | --- |
| **合规风险** | 涉政、涉黄、涉暴恐、辱骂、诈骗等违规内容漏过 | 被监管处罚、下架、刑事责任风险 |
| **体验风险** | 低质、标题党、搬运、垃圾广告污染信息流 | 用户流失、生态恶化、商业化受损 |
| **成本风险** | 全部靠人肉审核，人力成本与时效跟不上放量 | 审核积压、用户等待、效率低下 |

**机器审核链路的本质**，就是用「机器能力为主、人工兜底为辅」的方式，在**时效、成本、准确率**三者之间找到平衡，并对违规内容和低质内容分级处置。其中，「策略管理」决定机器怎么判，「用户分层管理」决定对不同的人用不同的策略和处置。

## 四、核心概念一句话版

- **机器审核**：用算法/模型对内容自动做「合规分类 + 质量分类」并给出处置动作。
- **策略**：把"什么内容算什么、怎么处置"沉淀成可配置、可灰度、可下线的规则集合。
- **用户分层**：按用户的历史行为与信任度分成白/灰/黑等层级，对不同层级用不同的审核力度与处置。
- **召回率 vs 准确率**：审核的核心权衡——抓得全（少漏判）还是抓得准（少误判）。
- **误判 vs 漏判**：误判伤了正常用户，漏判埋了合规风险，二者需要不同的补偿手段。

## 五、本知识库的三个设计原则

1. **链路完整**：不是只讲"用模型打分类"，而是从内容进来到处置到复盘讲全。
2. **策略与分层联动**：策略不脱离用户层单独存在，两者共同决定处置。
3. **可复盘可演进**：每一环都配指标，方便不断灰度、迭代、优化。
